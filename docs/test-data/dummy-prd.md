# Dummy PRD: Moonlight Table Booking

> This document is fake test data for Project Brain. The company, people, and numbers are invented.

## Overview

Moonlight Bistro is a fictional restaurant with one location and 20 tables. Today, staff take bookings by phone and write them in a paper diary. Moonlight Table Booking is a small web app that lets diners reserve a table online and lets staff manage the day's bookings.

## Goals

- Diners can book a table without calling the restaurant.
- Staff can see all bookings for a day on one screen.
- Fewer tables are double-booked.

## Users

- **Diner:** a member of the public who wants to reserve a table.
- **Host:** a staff member who manages bookings during a shift.
- **Manager:** the person who sets opening hours and table counts.

## Features

1. Diners can choose a date, time, and party size, then see whether a table is available.
2. Diners can book a table by entering a name and a phone number.
3. Diners receive a booking confirmation on screen with a reference code.
4. Hosts can view all bookings for a selected day.
5. Hosts can mark a booking as arrived or no-show.
6. Managers can set opening hours for each day of the week.
7. Managers can change the number of tables available.

## Business rules

- A booking lasts 90 minutes.
- A party can have between 1 and 8 people.
- Bookings can be made up to 30 days in advance.
- A table cannot be booked twice for overlapping times.

## Non-functional requirements

- The booking page should load quickly on a mobile phone.
- Only staff can see the list of bookings.

## Open areas

The team has not decided how diners cancel a booking, whether a deposit is needed, or what happens when a party is larger than 8 people.
